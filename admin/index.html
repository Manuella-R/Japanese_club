Admin sign-in

Paste your GitHub personal access token. It stays in this browser tab only (cleared when you close it) and is sent only to api.github.com.

Need a token? Which kind?

You own the repo (Manuella-R) → make a fine-grained token: Resource owner = you, Only select repositories → Japanese_club, Permissions → Contents: Read and write.

You are a collaborator (or the above doesn’t work) → make a classic token with the public_repo scope (the link pre-ticks it). Your account must also be added in the repo’s Settings → Collaborators and you must have accepted the invitation.

Then make sure your GitHub username is listed under Admins.
